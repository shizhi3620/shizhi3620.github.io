# Issue tracker: GitHub

Issues and specs for this repo live as GitHub Issues in `shizhi3620/shizhi3620.github.io`. Use the `gh` CLI for all operations.

## Conventions

- **Create an issue**: `gh issue create --repo shizhi3620/shizhi3620.github.io --title "..." --body "..."`.
- **Read an issue**: `gh issue view <number> --repo shizhi3620/shizhi3620.github.io --comments`.
- **List issues**: `gh issue list --repo shizhi3620/shizhi3620.github.io` with appropriate state and label filters.
- **Comment on an issue**: `gh issue comment <number> --repo shizhi3620/shizhi3620.github.io --body "..."`.
- **Apply or remove labels**: `gh issue edit <number> --repo shizhi3620/shizhi3620.github.io --add-label "..."` / `--remove-label "..."`.
- **Close**: `gh issue close <number> --repo shizhi3620/shizhi3620.github.io --comment "..."`.
